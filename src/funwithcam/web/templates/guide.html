使用说明

按家庭中的真实场景了解系统何时观察、何时询问，以及哪些判断仍需要孩子或家长确认。

到家与首次简报 开始学习 学习中离座 结束与检查 视频打卡 动作基准

到家与首次简报

适合工作日放学后或休息日第一次来到书桌附近时。

已支持
  1. 到达配置时间系统开始等待书桌区域有人稳定出现，不会到点就对空房间播报。
  2. 确认是孩子多帧人脸确认；家长、陌生人或多人画面不会触发。
  3. 播报今日安排包含当天课程、学校作业和下一次提醒时间。

开始学习

孩子吃完饭、准备开始后，可以使用语音或家长 Web 按钮。

已支持
说“开始学习”→检查画面、身份与光线→建立学习记录

明确默认口令可以直接执行；关键词组合或高影响操作会先告诉孩子可回答的确认口令。

学习中离开书桌

系统会记录离座并在达到阈值后自动暂停，但不会仅凭离座判断作业已经完成。

视觉监测已支持
正在学习保持学习记录
离开书桌超过配置阈值 ↓
暂时离开 / 自动暂停不判定为正常结束
孩子重新回来并确认身份 ↓
询问：继续学习还是结束学习？播报可明确回复的口令
继续学习开始前检查 → 恢复学习
结束学习进入当天完成情况检查
没有回答有限次数重问 → 保持暂停

持续离座后的自动暂停已经生效；暂停后视觉监测会停止。孩子回来后自动发起“继续还是结束”的询问仍待后续接入，目前可用语音或 Web 主动继续。

结束学习与完成情况检查

“结束学习”不是立即关掉记录，而是先核对今天实际录入的待完成任务。

语音流程已支持
  1. 确认结束意图孩子回答“检查完成情况”或“继续学习”。
  2. 逐项询问学校作业可由孩子确认；视频任务必须有打卡视频；家长确认型任务只能在 Web 完成。
  3. 记录证据并结束保留完成、稍后、跳过和视频等不同结果，便于回溯。

英语、古诗等视频打卡

用于需要保留朗读或背诵视频的任务。

已支持
说出打卡名称→准备材料→说“开始打卡”→说“打卡结束”→本地保存视频

达到配置的最长录制时间会自动保存。准备、开始、保存、取消和失败原因都会进入执行历史。

动作与光线基准

家长首次部署或调整摄像头位置、书桌位置后重新录入。

已支持
  1. 一次身份确认孩子先短暂正对摄像头。
  2. 采集真实动作依次采集舒服坐姿、正常写字、正常阅读和正常光线；低头写字不要求持续看到正脸。
  3. 家长检查图片查看原图和标注图，确认符合要求后发布新基准。
